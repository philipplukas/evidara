# Document Intelligence — Document Service

Interactive API reference for the read boundary exposed by document-intelligence, generated from `contracts/api/document-intelligence.openapi.yaml`.

This API is **not** the processing pipeline; it serves **published** document bodies to trusted consumers (primarily the legal-search BFF).
