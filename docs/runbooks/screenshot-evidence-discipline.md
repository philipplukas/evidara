# Screenshot / release evidence discipline

Owner: Platform / release  
Last reviewed: 2026-04-09  
Last verified: 2026-04-09  
Applies to: Phase-5 memos, walkthroughs, Linear gate issues

## When to attach screenshots

- **Branch protection** (TAR-77): GitHub rule showing required **Release Readiness** + one green workflow run.
- **MVP / walkthrough**: environment URL bar visible, timestamp or build identifier in frame when useful.
- **UI regressions**: before/after for the same viewport and locale.

## Naming and storage

- Prefer **Linear attachments** or **GitHub Actions artifacts** over unversioned chat drops.
- File name pattern: `YYYYMMDD-env-topic.png` (example: `20260409-staging-search-filters.png`).
