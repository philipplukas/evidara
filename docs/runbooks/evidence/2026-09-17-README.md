## Read the bundles knowing this

**The gates these runs passed were not the gates that existed that morning.** Six
defects had to be fixed first, and every one was a gate that could not pass on a
corpus that was fine:

| | |
|---|---|
| #1015 | legal-search read-back had no self-hosted auth, so `indexed_language_ok` and `indexed_title_ok` were NOT EVALUATED on every self-hosted run — a hole that disqualified the bundle |
| #1015 | content gates measured the RAW artifact, which for a PDF corpus is empty; they now measure the canonical text |
| #1015 | the read-back poll budget was sized for HTML and timed out on an extraction step |
| #1016 | the content-length floor was 10 KB, and Stadt Zürich's Hundevorschriften is 3,080 characters |
| #1017 | the density gate counted only `Art.`, so Basel-Stadt's 126 `§` markers read as no legal text |
| #1019 | the first-article gate knew only `Art. 1`, so an 1874 treaty numbered `Art. I`..`Art. VI` failed — and bare `Art\. 1` had always matched `Art. 12` |

The common cause is that the acceptance loop had only ever been exercised against
Fedlex HTML. Two of the six bundles record a non-default gate parameter, and the
summary states which: `min_content_length_floor` and `content_gate_source`.

## What these runs do NOT show

- **Two templates are still closed**, both on reference-seed gaps rather than
  gates: `de/bundesland_http_bayern` (`jur_de_by` has no authority in the seed)
  and `it/regione_http_lombardia` (`jur_it_lombardia` is not in the seed at all).
  `POST /v1/sources` refuses the pairing with "Authority does not belong to the
  requested jurisdiction."
- **`lexfind_api_bs_hunde` took two attempts**, and the first failure is worth
  knowing about. One document of five reached the index with the placeholder
  title `Document <id>`, no language and three of its six metadata rows, while
  the provider had captured the title correctly. It was filed as #1018 and closed
  as a symptom of #1012: `di-consumer` was OOMKilled seven times over exactly the
  window those documents were first processed, and this is what a PARTIAL record
  looks like once projected — searchable, full text intact, only the title giving
  it away. It self-corrected on reprocessing with no code change. The read-back
  gate (`indexed_title_ok`, added by #772) is what caught it.
- **`max_resources` scoped these runs.** Each captured a sample, not a corpus —
  8, 1 and 1 documents respectively, not the 944 an unscoped `lexfind_api_zh_full`
  run publishes. They prove the path works; they are not a coverage claim.
- **The gate set is a whitelist of drafting conventions.** French
  (`Article premier`) and Italian (`Art. 1-bis`) are not covered and will fail the
  same way the first time a real corpus reaches them.
